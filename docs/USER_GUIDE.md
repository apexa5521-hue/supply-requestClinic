## 1. الدخول والإعدادات الشخصية
- **الدخول**: افتح رابط النظام، اكتب **الاسم** و**الرقم السري** كما هما في تبويب `Users`، ثم «تسجيل الدخول». كل مستخدم يرى شاشته تلقائياً حسب دوره.
- **قفل مؤقت**: 5 محاولات خاطئة = قفل 5 دقائق.
- **تغيير الرقم السري**: زر القفل 🔒 بجانب اسمك (أسفل القائمة) — الرقم الحالي ثم الجديد (4 خانات على الأقل). الأدمن يستطيع إعادة تعيين رقم من نسيه.
- **اللغة**: زر «English / عربي» أعلى الصفحة. **الوضع الليلي**: زر القمر.
- **الجوال**: القائمة في الشريط السفلي، وباقي الإعدادات من زر «⋮» أعلى الشاشة.
- **المسودات**: كل طلب تكتبه يُحفظ على جهازك تلقائياً — لو انقطع الإنترنت لا يضيع، ويُرسل تلقائياً عند رجوع الاتصال، ولا يتكرر.

## 2. الأدوار والشاشات
الدور يُكتب في عمود `Role` بتبويب `Users`، وكل دور مربوط بشاشة في تبويب `Roles`.

| الدور (Role) | الشاشة | ما يظهر له في القائمة |
|---|---|---|
| **ممرضة** | `nurse` | طلب جديد · طلباتي · المعمل · العهدة · سير العمل |
| **طبيب** | `doctor` | المراجعات · المعمل · العهدة · سير العمل |
| **تموين** | `procurement` | الطلبات · البوكسات · العهدة · البلاغات · سير العمل |
| **المعمل** | `lab` | لوحة المعمل · مؤشرات المعمل · سير العمل |
| **جودة** | `quality` | حسب الصلاحيات (انظر القسم 3) |
| **تنفيذي** | `executive` | حسب الصلاحيات |
| **مالية** | `finance` | حسب الصلاحيات |
| **مدير فرع** | `branch` | حسب الصلاحيات — **وبيانات فرعه فقط** |
| **أدمن** | `admin` | كل الشاشات والصلاحيات دائماً |
| السواق | (بدون حساب) | صفحة تسليم البوكس بمسح QR + رابط «مهام السواق» |

ملاحظات:
- **الأدمن** لا يمكن تقليل صلاحياته، ولا يمكن حذف أو تغيير **آخر** أدمن.
- **مدير الفرع** يحتاج تحديد **الفرع** في حسابه (عمود `Branch`)؛ يرى طلبات وإرساليات وبلاغات وعهدة فرعه فقط (حسب فرع الطلب نفسه)، للاطلاع + التنبيه + الشكاوى، بدون اعتماد أو إرسال.
- **التموين** يمكن تقسيمه بالقسم: حقل «القسم» = **أسنان** يرى طلبات الأسنان فقط، **جلدية** يرى الجلدية فقط، فارغ = الكل (وتصله إيميلات قسمه فقط).

## 3. الصلاحيات
تُحدَّد لأدوار الإدارة (جودة، تنفيذي، مالية، مدير فرع، وأي دور إداري تنشئه). الأدوار التشغيلية (ممرضة، طبيب، تموين، المعمل) شاشاتها ثابتة.

| الصلاحية (في الشاشة) | الكود | ماذا تفتح |
|---|---|---|
| نظرة عامة | `overview` | مؤشرات الأداء والرسوم البيانية وآخر الطلبات |
| متابعة المواعيد | `monitor` | المتأخرات، دورة الطلب الشهري لكل طبيب، زر «تنبيه»، سجل التراجعات، الملخص اليومي بالإيميل |
| الأطباء — مباشر | `doctors_live` | طلبات كل طبيب المفتوحة حسب المرحلة، تتحدث كل دقيقة |
| التقارير والإحصائيات | `reports` | تقارير حسب الطبيب/الفرع/العيادة/الأصناف بالأسعار + تقرير أي طبيب + الحسبة المالية + Excel |
| شاشة المالية | `finance` | الصرف والتكلفة واتجاه 12 شهراً وجداول الأسعار |
| تعديل الأسعار | `prices_edit` | تعديل سعر أي صنف من شاشة المالية (يُكتب في الشيت مباشرة) |
| متابعة المعمل | `lab_view` | مؤشرات المعمل والمتأخرات والإعادات وتكلفة المعامل الخارجية |
| الأدوات والعهدة | `assets` | لوحة العهدة: البلاغات، التصليح والتالف وتكلفتها، النقص عن المعيار |
| عرض البلاغات | `complaints` | قائمة بلاغات الطلبات (تأخير/نقص/زيادة) |
| إغلاق البلاغات | `complaints_close` | إغلاق البلاغ بعد المعالجة |
| استبيان الأطباء | `surveys` | نتائج الاستبيان، من لم يعبّئه، والتذكير |
| أسعار الأطباء | `doctor_prices` | منح أو حجب رؤية الأسعار لكل طبيب |
| التنبيهات | `notices` | إرسال تعميم للتموين / التمريض / الأطباء / الجميع |
| المستخدمون والأدوار | `users` | إضافة الحسابات وتعديلها وتحديد صلاحيات الأدوار والنسخ الاحتياطي |

**الصلاحيات الافتراضية** (يمكن تغييرها من شاشة المستخدمين):

| الدور | الصلاحيات الافتراضية |
|---|---|
| جودة | نظرة عامة · متابعة المواعيد · الأطباء — مباشر · استبيان الأطباء · التقارير · متابعة المعمل · العهدة · البلاغات وإغلاقها · التنبيهات |
| تنفيذي | مثل الجودة |
| مالية | المالية · تعديل الأسعار · التقارير · متابعة المواعيد · العهدة |
| مدير فرع | نظرة عامة · التقارير · البلاغات · متابعة المواعيد · متابعة المعمل · العهدة (لفرعه فقط) |
| أدمن | كل شيء |

> السيرفر يتحقق من الصلاحية في كل عملية — إخفاء الزر وحده ليس هو الحماية. تغيير الصلاحية ينعكس فوراً بدون إعادة دخول.

### أسعار الأطباء ومدراء الفروع
- **الافتراضي لكل طبيب (أسنان وجلدية): بدون أسعار** — لا سعر ولا قيمة في أي مكان (اطلاع واعتماد فقط)، والأسعار لا تصل لجهازه أصلاً.
- **وكذلك مدير الفرع: بدون أسعار افتراضياً** — لا قيمة طلبات ولا تكلفة إرساليات المعمل الخارجية ولا قيمة العهدة أو تكلفة تصليحها أو التالف، في النظرة العامة والتقارير ومؤشرات المعمل والعهدة وملفات Excel. يرى الأعداد والأزمنة فقط.
- **المنح**: من صفحة **«أسعار الأطباء»** — تظهر لمن لديه صلاحية «أسعار الأطباء» (**الإدارة التنفيذية والجودة والمالية** افتراضياً، والأدمن). زر «منح الأسعار» / «حجب الأسعار» لكل طبيب أو مدير فرع (عليه علامة «مدير فرع»)، ويُسجَّل في `Log` باسم من غيّر.
- أو من شاشة المستخدمين (تعديل حساب الطبيب أو مدير الفرع ◂ «الأسعار التي يراها الطبيب»)، أو عمود `PriceView` في `Users`: `يرى الأسعار` أو `بدون أسعار` (الفارغ = بدون أسعار).

## 4. إدارة المستخدمين والأدوار (للأدمن)
من القائمة ◂ **المستخدمون**.

### إضافة مستخدم
«مستخدم جديد» ثم:

| الحقل | لمن | الملاحظة |
|---|---|---|
| الاسم + الرقم السري | الكل | الاسم هو اسم الدخول؛ الرقم يُحفظ مشفّراً |
| الدور | الكل | من قائمة الأدوار |
| البريد | اختياري | لإشعارات البريد |
| العيادات | الممرضة | عياداتها (تظهر في «طلب طبيب») |
| القسم | التموين / الطبيب | أسنان / جلدية / فارغ = الكل |
| الفرع | أدوار الإدارة | مدير الفرع: فرعه · فارغ = كل الفروع |
| الطبيب المرتبط | الطبيب | اسم الطبيب كما في تبويب `Doctors` (إن اختلف اسم الدخول) |
| الأسعار التي يراها الطبيب | الطبيب | انظر القسم 3 |

- **تعديل**: زر «تعديل» على المستخدم — ترك الرقم السري فارغاً = لا يتغير.
- **حذف**: من نافذة التعديل (لا يمكن حذف نفسك أو آخر أدمن).
- تنبيه أعلى الشاشة بالأطباء **الذين بلا حساب** — طلباتهم تذهب للتموين مباشرة بدون اعتماد.

### الأدوار وصلاحياتها
في نفس الشاشة جدول **«الأدوار والشاشات»**:
- «تعديل» على أي دور ◂ اختر الشاشة ◂ علّم الصلاحيات ✓ ◂ حفظ.
- «دور جديد» لإنشاء دور إداري باسمك (مثلاً «مشرف جودة الفرع») وتحديد صلاحياته.

### أقسام أخرى في الشاشة
- **النسخ الاحتياطية**: «نسخة احتياطية الآن» + رابط آخر نسخة والمجلد.
- **تجهيز النظام بعد التحديث**: يعمل تلقائياً بعد كل تحديث — هنا ترى نتيجة كل خطوة و«تشغيل التجهيز الآن».

## 5. إعداد الشيت (التبويبات والأعمدة)
الأعمدة تُقرأ **بالاسم** (الترتيب لا يهم)، وأي عمود ناقص يُضاف تلقائياً في آخر التبويب. التعديل اليدوي يظهر في النظام بعد تحديث الصفحة.

| التبويب | الأعمدة المهمة | ملاحظات |
|---|---|---|
| `Users` | Name · Password · Role · Clinic · Email · DoctorName · Department · Branch · PriceView | Clinic للممرضة (عدة عيادات بفاصلة) |
| `Roles` | RoleName · Screen · Permissions | تُدار من شاشة المستخدمين |
| `Clinics` | ClinicName · Branch · Type | Type: Dentistry / Dermatology / Sterilization / Triage — المرجع الوحيد للعيادات |
| `Doctors` | DoctorName · Clinic · NurseName · Subspecialty · **Billing** | Billing: `عيادة` (ثابت) أو `بوكس`/فارغ — انظر القسم 8 |
| `ItemsCatalog` | ItemName · CommercialName · Category · **Price** · Ownership · Serialized · Department | Price رقم فقط · Ownership=`عهدة` لأدوات الشركة · Serialized=`نعم` للمسلسلة · Department أسنان/جلدية/فارغ=مشترك |
| `Labs` | LabName · Type (داخلي/خارجي) · Email · Phone · Active · TurnaroundDays | المعامل النشطة تظهر في القوائم |
| `LabWorkTypes` / `LabMaterials` | WorkType / Material | قوائم المعمل |
| `ClinicStandards` | (من شاشة العهدة) | معيار كل أداة لكل عيادة |
| `Settings` | Key · Value | انظر الجدول التالي |

تبويبات تُنشأ وتُعبّأ تلقائياً (لا تعدّلها يدوياً إلا للضرورة): `Requests` · `RequestItems` · `Shipments` · `ShipmentItems` · `Comments` · `Notices` · `Complaints` · `Reversals` · `LabCases` · `LabItems` · `LabNotes` · `Assets` · `AssetTickets` · `Boxes` · `BoxMoves` · `Log`.

### مفاتيح تبويب Settings (اختيارية)
| Key | القيمة | الأثر |
|---|---|---|
| `LabTurnaroundDays` | رقم (افتراضي 10) | أيام التنفيذ الافتراضية لموعد المعمل |
| `IteroLab` | اسم معمل | المعمل الذي تذهب له حالات iTero (افتراضياً الداخلي) |
| `BackdateUntil` | تاريخ `YYYY-MM-DD` أو `off` | مدة خاصية «طلب سابق بأثر رجعي» (افتراضياً حتى 2026-11-04) |
| `DriverEmail` | إيميل | إشعار السواق مع كل بوكس جاهز |
| `DriverToken` | (يُنشأ تلقائياً) | غيّره لإبطال رابط «مهام السواق» القديم |

## 6. دورة الطلب والحالات والمواعيد
**رفع الطلب ← مراجعة الطبيب واعتماده ← التجهيز (← المندوب اختياري) ← الإرسال (شحنة أو أكثر) ← وصل الفرع (بوكس) ← الاستلام بالتوقيع**

| الحالة | المعنى | عند من |
|---|---|---|
| مراجعة الطبيب | بانتظار اعتماد الطبيب | الطبيب |
| جديد | طبيب بلا حساب أو مستهلكات عيادة — جاهز للتموين | التموين |
| معتمد من الطبيب | اعتمده الطبيب | التموين |
| قيد التجهيز / بانتظار المندوب / استلم المندوب | التموين يجهّز | التموين |
| تم الإرسال | أُرسل كل شيء | الممرضة (الاستلام) |
| تم الاستلام | اكتمل بالتوقيع | — |
| مرفوض | رفضه الطبيب مع السبب — يعود للممرضة | الممرضة |

**المواعيد:**
- **الشهري**: يُرفع من يوم **15 إلى 20**، ويجب أن يُستلم قبل نهاية **يوم 1** من الشهر التالي. الرفع بعد يوم 20 مسموح لكنه يُعلَّم «رُفع متأخراً».
- **الطارئ**: الهدف إرساله خلال **ساعتين**، والحد الأقصى **48 ساعة**، وعلى هذا الزمن يُقيَّم التموين.
- **«مستهلكات عيادة»** للتعقيم وغرفة الفرز فقط (بدون طبيب)؛ أي عيادة أخرى تُطلب «طلب طبيب».

## 7. طريقة العمل لكل دور

### الممرضة
1. **طلب طبيب**: «طلب جديد» ◂ «طلب طبيب» ◂ اختر **العيادة** ثم **الطبيب** (أطباء العيادة أولاً ثم الباقي) ◂ الفرع ◂ شهري/طارئ ◂ أضف الأصناف (من الكتالوج فقط، أو «البكج المعتاد» للطبيب) ◂ «إرسال الطلب». يذهب لصفحة الطبيب للاعتماد.
2. **مستهلكات عيادة**: للتعقيم أو غرفة الفرز (أي فرع) — يذهب للتموين مباشرة.
3. **طلب سابق (بأثر رجعي)** — مؤقت: علّم الخانة واكتب التاريخ الفعلي؛ يُسجَّل «تم الاستلام» بعلامة «أثر رجعي».
4. **متابعة**: «طلباتي» — الفلاتر بالأعلى، «التفاصيل» لمراحل الطلب والتعليقات، و«إبلاغ عن مشكلة» (تأخير/نقص/زيادة).
5. **إعادة للطبيب**: الطلب المرفوض ◂ عدّل ◂ «إعادة الإرسال للطبيب».
6. **الاستلام**: عند وصول الشحنة («وصل الفرع» أو «تم الإرسال») ◂ «استلام وتوقيع» ◂ اكتب الكميات المستلمة فعلاً ◂ وقّع ◂ تأكيد. كل شحنة توقَّع لوحدها.
7. **المعمل**: «طلب جديد» ◂ «إرسال للمعمل»:
   - **حالة جديدة**: الطبيب · الفرع · رقم الملف · تاريخ السكان · الأعمال (المعمل · نوع العمل · ملاحظات · صور) ◂ إرسال.
   - **Remake**: ابحث برقم الملف ◂ اختر الحالة والأعمال ◂ السبب والوصف وتاريخ سكان الإعادة.
   - **iTero**: تاريخ السكان · رقم حالة iTero · رقم الملف · الطبيب ◂ إرسال.
   - صفحة «المعمل»: تتابع الإرساليات وتضغط «تأكيد الاستلام» عند وصول العمل.
8. **العهدة**: أدوات عيادتك بأرقامها التسلسلية ◂ «بلاغ» على القطعة (خربانة مع صورة / كفاءة متدنية / مفقودة).

### الطبيب
1. «المراجعات»: البطاقات بالأعلى (بانتظار مراجعتك، المعتمدة، المرسلة، المستلمة).
2. افتح الطلب ◂ عدّل الكمية أو اكتب ملاحظة لأي صنف ◂ **اعتماد** (يذهب للتموين بالكميات التي اعتمدتها)، أو اكتب السبب ◂ **رفض** (يعود للممرضة).
3. «تقرير الطلبات»: لشهر أو تراكمي حتى تاريخ — طباعة/PDF أو Excel (الأسعار حسب صلاحيتك).
4. «المعمل»: متابعة إرساليات مرضاك (اطلاع).

### التموين
1. «الطلبات»: الفلاتر بالمرحلة (لدى الطبيب، جاهز للتجهيز، قيد التجهيز، مرسل جزئياً…) والفرع والبحث.
2. افتح «الأصناف والاعتماد» ◂ حدّد **حالة كل صنف** (قيد التجهيز / بانتظار المندوب / استلم المندوب).
3. **الإرسال**: علّم الأصناف واكتب «كمية هذه الشحنة» (المتوفر الآن والباقي يبقى مفتوحاً) ◂ «إرسال المحدد كشحنة». تُحمَّل في بوكس الطبيب ويُبلَّغ الممرضة.
4. **التراجع**: «تراجع عن آخر خطوة» مع السبب (يُسجَّل للجودة).
5. «التفاصيل» ◂ «طباعة / PDF» لورقة التجهيز والتوقيع.
6. **البوكسات**: مكان كل بوكس وحالته · «طلب نقل» · طباعة ستيكرات QR · رابط «مهام السواق» يُرسل للسواق مرة واحدة.
7. **العهدة**: المعيار لكل عيادة · صرف الأدوات بأرقامها التسلسلية · معالجة البلاغات (استلام بصورة ◂ تصليح بالتكلفة ◂ إرجاع، أو تالف/مفقود ◂ صرف بديل) · البحث بالرقم التسلسلي.
8. **البلاغات**: اقرأ ورد في تعليقات الطلب (الإغلاق للجودة).

### السواق (بدون حساب)
- امسح QR البوكس ◂ اختر **وين سلّمته** ◂ صوّر البوكس (إجباري) ◂ اسمك ◂ **«تسليم»**. لا يمكن التسليم لنفس المكان مرتين.
- رابط «مهام السواق» (أضفه لشاشة الجوال): البوكسات المطلوب نقلها ووجهتها.

### المعمل
1. «لوحة المعمل»: الفلاتر (جديد، قيد العمل، عند معمل خارجي، جاهز، متأخر، إعادات) والبحث برقم الملف.
2. لكل عمل: **استلام ◂ بدء العمل ◂ (معمل خارجي: المعمل + موعد الرجوع + التكلفة) ◂ جاهز ◂ إرسال للعيادة**، أو «تحويل» لمعمل آخر.
3. «التفاصيل»: المراحل كاملة والملاحظات. «مؤشرات المعمل»: زمن الإنجاز والالتزام والإعادات والتكلفة.

### الجودة
1. «متابعة المواعيد»: دورة الطلب الشهري لكل طبيب، المتأخر وأين يقف، **«تنبيه»** لصاحب المرحلة، و**سجل التراجعات** أسفل الصفحة.
2. «الأطباء — مباشر»: طلبات كل طبيب المفتوحة حسب المرحلة (اضغط الرقم لفتح الطلبات).
3. «البلاغات»: افتح الطلب للتحقق ◂ «إغلاق».
4. «التقارير»: الفترة والفرع ◂ «تحديث» ◂ الجداول + Excel + تقرير أي طبيب.
5. «التنبيهات»: اختر الجهة ◂ اكتب ◂ «إرسال» (يظهر أعلى صفحتهم).

### الإدارة التنفيذية
«نظرة عامة» (المؤشرات والرسوم، اختيار الشهر أو كل الفترة) · «التقارير» · «الأطباء — مباشر» · «مؤشرات المعمل» · «الأدوات والعهدة» · «سير العمل».

### المالية
«المالية»: الصرف حسب الفترة والفرع (المطلوب، المعتمد، وفر مراجعة الطبيب، المرسل، المستلم، الطارئ)، اتجاه 12 شهراً، **الحسبة المالية للأطباء**، وجدول الأسعار — **تعديل السعر** يُكتب في الشيت ويُسجَّل في `Log`.

### مدير الفرع
نفس شاشات الإدارة لكن **لفرعه فقط**: نظرة عامة، المتابعة والتنبيه، التقارير، مؤشرات المعمل، العهدة، البلاغات.
**بدون أي أسعار أو قيم** إلا إذا منحته الإدارة التنفيذية أو الجودة أو المالية الأسعار من صفحة «أسعار الأطباء».

## 8. الحسبة المالية للأطباء
في تبويب `Doctors` عمود **`Billing`**:
- **`عيادة`** — طبيب ثابت: تُحسب عليه **كل مستهلكات عيادته** (عيادته = أول عيادة في عمود `Clinic`).
- **`بوكس`** أو فارغ — يُحسب عليه **ما يُطلب باسمه فقط** (في أي عيادة).

**كل طلب يُحسب مرة واحدة**: طبيب البوكس صاحب الطلب ← وإلا الطبيب الثابت في عيادة الطلب ← وإلا صاحب الطلب ← وإلا «غير محسوب على طبيب» (التعقيم والفرز).
الحسبة للمستهلكات بأسعار الكتالوج (أدوات العهدة على الشركة ولا تُحسب)، وتظهر في «التقارير» و«المالية» وتصدير Excel.

## 8.1 استبيان رضا الأطباء
- **الدورة**: يفتح كل **50 يوماً** ويبقى مفتوحاً **10 أيام**. **أول دورة بعد 50 يوماً من التحديث** (التاريخ في `SurveyStart` بتبويب Settings — غيّره لتقديمها أو تأخيرها). للتغيير: `SurveyEveryDays` و`SurveyOpenDays`، ولإيقافه: `SurveyEnabled` = `لا`.
- **الطبيب**: نافذة عند الدخول مرة باليوم (مع «لاحقاً») + شريط أعلى صفحته «استبيان الرضا بانتظارك» حتى يعبّئه. الإجابات باسمه، ومرة واحدة لكل دورة.
- **الأسئلة**: تبويب `SurveyQuestions` — QID · Question · QuestionEn · Type (`stars` 1–5 / `nps` 0–10 / `text`) · Section · Required (نعم/لا) · Active (نعم/لا) · Order. التعديل يطبَّق من **الدورة التالية** (الدورة المفتوحة تكمل بأسئلتها).
- **النتائج** (صلاحية «استبيان الأطباء» — الجودة والتنفيذي): نسبة الإجابة، متوسط الرضا، مؤشر التوصية NPS، نتيجة كل سؤال، حسب الفرع، الاتجاه بين الدورات، الملاحظات المكتوبة، وإجابة كل طبيب، مع **«لم يعبّئوا بعد» وزر «تذكير»** (إيميل) وتصدير Excel. الإجابات محفوظة في تبويب `SurveyResponses`.

## 9. النسخ الاحتياطي والتحديث
- **نسخة تلقائية كل ليلة (2 فجراً)** في Drive بمجلد «مسار — نسخ احتياطية» (آخر 30 نسخة). يدوياً: المستخدمون ◂ «نسخة احتياطية الآن».
- **الاسترجاع**: افتح النسخة ◂ File ◂ Make a copy، أو انسخ التبويب/الصفوف المطلوبة. وللرجوع السريع: File ◂ Version history.
- **تحديث النظام بعد أي تعديل في الكود**:
  1. انسخ `Code.gs` و`JavaScript.html` و`Index.html` من GitHub (فرع `main`) إلى مشروع Apps Script.
  2. **Deploy ◂ Manage deployments ◂ ✏️ ◂ Version: New version ◂ Deploy**.
  3. أول دخول بعدها يجهّز أي تبويب/عمود/صلاحية جديدة تلقائياً.
- **مهم**: النشر يجب أن يكون **Who has access: Anyone** (صفحة السواق تعمل بدون دخول).

### الرفع على استضافة/دومين فرعي (لسرعة الفتح)
الخادم والبيانات يبقون في Google (Apps Script + Sheets)، وتُستضاف **الواجهة فقط** على دومينكم الفرعي فتفتح أسرع (صفحة واحدة بحجم ~200KB مضغوطة بدل صفحة Apps Script).
1. من المطوّر: `node scripts/build-static.js` ينتج مجلد `dist/` وملف `masar-web.zip` (فيه `index.html` + `.htaccess` + مثال nginx + تعليمات).
2. فك الضغط وارفع **محتوى** المجلد إلى مجلد الدومين الفرعي (cPanel ◂ File Manager ◂ مجلد الدومين الفرعي ◂ Upload). فعّل «Show hidden files» لرؤية `.htaccess`.
3. فعّل شهادة **HTTPS** للدومين الفرعي (AutoSSL في cPanel أو Let's Encrypt).
4. تأكد أن Apps Script ◂ Deploy ◂ **Who has access = Anyone**.
5. افتح `https://الدومين-الفرعي` — تظهر شاشة الدخول. روابط QR للبوكسات ومهام السواق تُبنى تلقائياً على هذا الدومين.
- **عند تحديث الكود**: حدّث Apps Script (Code.gs) كالمعتاد **و**أعد بناء الحزمة وارفع `index.html` فقط.
- **عند إنشاء نشر جديد لـ Apps Script** (رابط جديد): `node scripts/build-static.js https://script.google.com/macros/s/…/exec`.
- **ملاحظة**: السرعة بعد أول فتح تعتمد على Apps Script (الدخول وكل عملية تمر عليه) — الاستضافة تسرّع **فتح الصفحة** فقط، والنظام أصلاً يخزّن البيانات ويعرض آخر نسخة فوراً.

## 10. أسئلة شائعة وحل المشكلات
| المشكلة | الحل |
|---|---|
| الطبيب لا يرى طلبات ممرضته | تأكد أن اسمه في `Doctors` يطابق حسابه، أو اختر «الطبيب المرتبط» في حسابه |
| طلبات طبيب تذهب للتموين بدون اعتماد | الطبيب بلا حساب — أنشئ له حساباً بدور «طبيب» |
